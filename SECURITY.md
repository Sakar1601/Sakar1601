# Security Policy

## Supported versions

Only the latest commit on `main` receives fixes.

## Reporting a vulnerability

This repository is a profile README with a small SVG generator; it has no deployed service. If you still find a
security problem, please do **not** open a public issue. Report it privately through GitHub:
[Report a vulnerability](https://github.com/Sakar1601/Sakar1601/security/advisories/new).

## Secrets

No credentials are used in this repository. The daily workflow runs with the default `GITHUB_TOKEN`.
